4. Map art direction

A Redline map

Built from the system's tokens, never vendor defaults. Communities are areas, listings are plots, and the redline boundary appears only when a community is selected.

Schematic geometry and plot positions for demonstration. Production uses MapLibre with a custom style on vector tiles; plot pins need real coordinates (open question Q3).

Map language

  • Land and waterSheet land, pale slate water, a deeper band along coasts.
  • Community areaHairline outline, no fill. Tinted on hover.
  • Selected communityThe redline: crimson boundary and tint, only as a state.
  • ClusterInk disc with a count. Three sizes: 1, 2 to 5, 6 or more.
  • Plot markerA square for a plot, not a teardrop.
  • Active plotCrimson marker and a figure-first price tag.
  • ShortlistedCrimson outline, so it stays findable.
