# Bundled map data (specimen only)

Generated by `python3 tools/map/fetch_tiles.py docs/stage-03-3-v2/map`. Do not edit by hand.

- **Tiles:** OpenStreetMap vector tiles from OpenFreeMap (planet build `20261004_113936_pt`), z8–13 over W54.25 S24.15 E54.80 N24.62.
- **Style:** OpenFreeMap "liberty", rewritten to local tiles, English and Latin labels, no raster layer.
- **Glyphs:** Noto Sans, Latin and Arabic ranges.
- **Sprite:** `ofm`.

**Format:** the artifact host serves no generic binary type, so tiles and glyphs are stored as base64 JSON packs in `packs/`:
- tiles grouped by zoom and z10 column;
- glyphs grouped by font and by Latin or Arabic blocks.

`map.js` reads the packs through an `aa-pack://` MapLibre protocol. The raw `.pbf` cache in `src/` is not committed.

The artifact host cannot load third-party tiles at runtime, so the specimen ships this bounded set.

**Licence:** map data © OpenStreetMap contributors, available under the Open Database Licence (ODbL), https://www.openstreetmap.org/copyright. Tiles and style are by OpenFreeMap. The attribution is shown on every map.

**Production:** the tile source is not decided (D-006). This set is not a production asset.
